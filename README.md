# Blinkit Sales Performance Dashboard

## Project Overview

This project is an interactive Microsoft Excel dashboard developed to analyze Blinkit sales performance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## KPIs

- Total Revenue
- Total Cost
- Total Profit
- Average Margin
- Best Month
- Best Category

## Dashboard Features

- Monthly Revenue Analysis
- Category-wise Profit Analysis
- State-wise Profit Analysis
- Interactive Filters

## Skills

- Data Cleaning
- Dashboard Design
- Business Analysis
- Data Visualization
